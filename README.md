# 💻 Portfólio Pessoal - Thiago Mouzer

Este é o repositório do meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades técnicas e trajetórias no mundo do desenvolvimento de software. 
O site foi construído com foco em responsividade, performance e uma experiência de usuário fluida.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

* **HTML5** - Estruturação de conteúdo.
* **CSS3** - Estilização e layout (Flexbox/Grid).
* **JavaScript (ES6+)** - Lógica e interatividade.
* **ScrollReveal.js** - Biblioteca para animações de scroll.
* **Boxicons** - Ícones modernos para a interface.

---

## 🖥️ Seções do Site

1.  **Home:** Apresentação inicial com call-to-action.
2.  **Sobre:** Um pouco sobre minha trajetória e objetivos.
3.  **Habilidades:** Lista das tecnologias que domino (Front-end, Design, etc).
4.  **Projetos (Works):** Galeria visual com links para os repositórios ou demos de projetos reais.
5.  **Contato:** Links diretos para redes profissionais e formulário/e-mail.

---

## 🎨 Design e Funcionalidades

-   **Responsividade:** Adaptado para dispositivos móveis, tablets e desktops.
-   **Animações:** Efeitos de surgimento (fade-in) ao rolar a página para uma navegação mais dinâmica.
-   **Clean Code:** Estrutura de arquivos organizada e fácil manutenção.
